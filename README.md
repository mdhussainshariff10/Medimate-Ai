 MediMate AI 💊

An AI-Powered Medicine Information and Voice Assistant**

MediMate AI is a Python-based desktop application that helps users access medicine information through AI, voice interaction, and medicine label scanning.

✨ Features
 AI-powered medicine information using Google Gemini
 Voice-based interaction
 Medicine label scanning using OpenCV
 Text extraction using Tesseract OCR
 AI-based medicine information analysis
 Text-to-speech using Edge TTS
 Interactive desktop dashboard using PySide6

 🛠️ Tech Stack
Python | PySide6 | Google Gemini | OpenCV | Tesseract OCR | SpeechRecognition | Edge TTS



 🏆 Achievement
2nd Place – Panel 6, UDBHAV 3.0 Project Expo**
